# 基于第一性原理 · 轻量化永动知识图谱Agent

## 设计理念

严格遵循第一性原理，剥离所有行业经验、框架套路、冗余工程，只保留不可再分、不可替代的底层公理。

### 三大核心公理

1. **存续公理（Alive）**：系统运行闭环永不终止，局部异常永远不能击穿整体系统
2. **记忆公理（Memory）**：智能体的智能 = 结构化、可沉淀、可关联、可检索、可推演的历史经验
3. **自驱公理（Self-Drive）**：无外部输入时，系统必须自我产生任务、自我梳理知识、自我精简迭代

### 三层极简单向依赖架构

1. **存续保活层（底层）**：负责系统永久在线、异常隔离、资源管控、自愈恢复
2. **知识记忆层（中层）**：以轻量化知识图谱为核心，存储实体、关系、权重，沉淀所有运行经验
3. **自驱进化层（上层）**：基于图谱关联关系自动生成新任务、空闲自动复盘、自动精简知识、迭代优化权重

## 快速开始

### 零依赖运行

无需任何外部依赖，纯Python实现：

```bash
# 运行基础测试
python test_basic.py

# 启动永动智能体
python main.py
```

## 核心特性

- ✅ **零外部服务依赖**：无数据库、无Redis、无MQ、无Neo4j
- ✅ **全本地文件持久化**：断电、重启、崩溃不丢失记忆
- ✅ **无冗余逻辑**：所有代码可被三大公理解释
- ✅ **低资源稳态运行**：空闲极低负载
- ✅ **完全自闭环**：无需人工干预、无需外部API持续输入
